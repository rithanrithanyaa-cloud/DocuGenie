# 🧞 DocuGenie

**LLM-Powered Enterprise Knowledge Discovery Assistant**

DocuGenie is a Retrieval-Augmented Generation (RAG) system that lets employees upload company documents and ask questions in natural language. Answers are grounded in the uploaded documents, come with source citations, and are generated by a **locally fine-tuned Flan-T5-Small model**, so no external LLM API is needed.

---

## ✨ Features

### Core
- 📄 **Multi-format ingestion**: upload and index 5 document formats (PDF, DOCX, TXT, etc.)
- 🔎 **Semantic retrieval**: `all-MiniLM-L6-v2` embeddings stored in ChromaDB
- 🤖 **Local answer generation**: fine-tuned Flan-T5-Small (API-free)
- 📌 **Citations**: every answer shows the source document and passage
- 🎯 **Confidence badges**: quick signal on how well-supported an answer is
- 🛡️ **Hallucination guard rail**: if the knowledge base lacks the answer, DocuGenie says so instead of guessing
- 💬 **Chat history** and **suggested follow-up questions**
- 👍👎 **Feedback buttons** on every answer

### Enterprise
- 🔐 **Login / Signup with Role-Based Access Control** (HR, Finance, IT, Admin, Marketing, Legal, Sales, All Employees)
- 📊 **Analytics dashboard**
- 🕳️ **Missing Content ("Gaps")**: admins are notified about questions the documents could not answer
- 🚨 **Sensitive Query escalation**: sensitive questions are routed to HR, with a notify-back loop to the employee

### Accessibility & Usability
- 🌐 **Multilingual**: English / Tamil toggle
- 🎙️ **Voice input and output**
- 📥 **PDF export** of answers
- ⚙️ **Adjustable retrieval settings**: chunk size, overlap, Top-K

## 🏗️ Architecture

```
Documents ─► Parsing ─► Chunking ─► MiniLM Embeddings ─► ChromaDB
                                                            │
User Query ─► Embedding ─► Top-K Retrieval ◄────────────────┘
                               │
                               ▼
              Flan-T5-Small (fine-tuned) ─► Answer + Citations + Confidence
```

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- pip

### Installation

```bash
git clone https://github.com/<your-username>/DocuGenie.git
cd DocuGenie
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Run

```bash
python app.py
```

Then open `http://localhost:5000` (adjust to your port) in your browser.

---

## 📖 Usage

1. Sign up / log in with your department role.
2. Upload documents in the **Upload** panel; they appear in the **Indexed Library**.
3. Tune chunk size, overlap and Top-K under **Retrieval Settings** if needed.
4. Ask a question in the chat and review the answer, citations and confidence badge.
5. Give 👍/👎 feedback, export to PDF, or use voice and Tamil mode.
